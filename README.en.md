# DocsAndDragons - D&D 5E Reference
[Leia em Português](README.md) \
A quick reference for core materials of Dungeons & Dragons, 5th Edition.

> This application is designed to help players and DMs quickly find **rules** and **references** using a smart, non-AI search.

## About

DocsAndDragons is a project that **provides a fast, practical interface for consulting D&D 5E content**. It uses JSON data and keyword-based search to return relevant results in a Vue.js interface.

## Features

- Keyword search across core D&D 5E content
- Interface aimed at both players and Dungeon Masters
- Lightweight, easily maintainable data structure

## Technical Goals

- Implement fuzzy search without using AI, agents, or LLMs
- Build the interface with Vue.js
- Apply web development best practices
- Keep data maintenance easy with structured JSON files

## Project Structure

- `src/` Vue.js application source code
- `public/` public assets
- `data/` JSON files with reference material
