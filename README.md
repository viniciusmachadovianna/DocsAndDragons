# DocsAndDragons - Consulta D&D 5E

Uma fonte de consulta dos materiais-base de "Dungeons and Dragons" 5ª edição.

> Criado para ajudar jogadores e mestres a encontrar **regras** e **referências** rapidamente, com pesquisa inteligente e flexível. Não é necessário criar conta para utilizar.

## Sobre

DocsAndDragons é um projeto para **consulta rápida de conteúdos de D&D 5E**. Ele usa dados em JSON e uma busca por palavras-chave para oferecer resultados eficientes em uma interface Vue.js.

## Objetivos técnicos

- Implementar busca fuzzy sem IA, agentes ou LLM
- Desenvolver a interface com Vue.js
- Aplicar boas práticas de desenvolvimento WEB
- Facilitar manutenção com dados estruturados em JSON

## Funcionalidades

- Pesquisa por palavras-chave em material-base de D&D 5E
- Interface voltada a jogadores e mestres
- Estrutura de dados leve e fácil de manter

## Linha do tempo

1. Consulta de conteúdo em JSON
2. Lógica de pesquisa por palavras-chave via script
3. Interface em Vue.js voltada ao público-alvo
